# Multi-Utility Toolkit 🛠️

## 📌 Project Description
The Multi-Utility Toolkit is a Python-based application that provides multiple useful tools in one program. It allows users to perform date and time calculations, mathematical operations, random data generation, file handling, UUID generation, and Python module exploration through a menu-driven interface.

## ✨ Features

### 1. Date and Time Operations
- Display the current date and time.
- Calculate the difference between two dates.
- Format dates using custom formats.
- Measure elapsed time with a stopwatch.
- Run a countdown timer.

### 2. Mathematical Operations
- Calculate the factorial of a number.
- Calculate compound interest.
- Perform trigonometric calculations (sin, cos, and tan).
- Calculate the area of a circle and rectangle.

### 3. Random Data Generation
- Generate random numbers within a specified range.
- Generate a list of random numbers.
- Create random passwords.
- Generate six-digit OTPs.

### 4. Unique Identifier Generation
- Generate unique identifiers using UUID version 4.

### 5. File Operations
- Create new files.
- Write data to files.
- Read file contents.
- Append data to existing files.

### 6. Python Module Exploration
- Import Python modules dynamically.
- Explore module attributes using the `dir()` function.
- Display available attributes of a selected module.

## 🛠️ Technologies Used
- **Python 3**
- `os` — File and directory operations.
- `datetime` — Date and time handling.
- `time` — Stopwatch and countdown timer.
- `math` — Mathematical calculations.
- `random` — Random number and data generation.
- `uuid` — Unique identifier generation.
- `string` — Characters for password generation.
- `importlib` — Dynamic module importing.

## 📋 Requirements
- Python 3 installed on your computer.
- A code editor such as Visual Studio Code (optional).

All modules used in this project are part of Python's standard library. No external packages are required.

## 🚀 How to Run

1. Download or clone this repository.
2. Save the Python code in a file named `main.py`.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

5. Select an option from the main menu.
6. Follow the instructions displayed on the screen.
